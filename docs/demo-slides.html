Backend architecture

Source metadata and owned media stay separated until import is explicitly requested.

Source APIsAniList GraphQL and MangaDex REST provide metadata, IDs, covers, and chapter references.
>
MangaHub APINormalizes records, enforces auth/admin roles, syncs catalog rows, and imports licensed pages.
>
Neon + R2Postgres stores manga/chapter records. R2 stores chapter images and imported licensed assets.
Admin and auth

Uploads and imports are gated by real user roles.

User roles
  • Users register/login with bcrypt and JWT.
  • JWTs include `role`.
  • `/users/me` exposes the current user and role.
  • `ADMIN_EMAILS` promotes configured accounts to admin.
Admin operations
  • Create, edit, delete manga.
  • Create, upload, edit, delete chapters.
  • Sync AniList and MangaDex metadata.
  • Import licensed MangaDex media into R2/local storage.
MangaDex + R2

Licensed import turns external chapter pages into MangaHub-owned storage URLs.

Admin APIR2/local storage adapter
POST /admin/import/mangadex/:id
Authorization: Bearer <admin-jwt>

{
  "language": "en",
  "quality": "data-saver",
  "limit": 3,
  "rights_status": "licensed-import",
  "import_cover": true
}

Result:
- upserts MangaDex title into MangaHub catalog
- fetches MangaDex@Home pages
- writes images through ChapterStorage.SaveBytes
- stores chapter page_urls as R2/local URLs
